# 结构化输出(TypedDict/Pydantic/Annotated)

### 使用Pydantic + Field约束
```python
from typing import Annotated
from pydantic import BaseModel, Field, ValidationError
Age=Annotated[int,Field(ge=0,le=150,description="年龄，范围0-150")]
class Man(BaseModel):
    name:str
    age:int
    sex:bool
    age2:Age
try:
    man=Man(name="zhangsan",age=11,sex=1,age2=188)
    print(man)
except ValidationError as e:
    print("数据校验失败")
    print(e)
```

### TypedDict
```python
from typing import Annotated,TypedDict
Age = Anotated[int,"年龄，范围0-150"]
Class Man(TypedDict):
    name: str
    age: int
    sex: bool
    age2: Age
man=Man(name="test",age="1111")
```
