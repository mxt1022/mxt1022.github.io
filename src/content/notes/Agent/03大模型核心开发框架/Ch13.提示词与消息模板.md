### 外部文件
```python
from langchain_core.prompts import load_prompt
template= load_prompt("prompt.json",encoding="utf-8")
print(template.format(name="zhangsan",what="funny"))
```
prompt是指定的提示词文件，通过json文件格式加载模板，编码格式为utf-8

```python
from  langchain_core.prompts import PromptTemplete
template = PromptTemplete.from_templete{
    "test {role}, test{question}"
}
prompt=templete.format(role="python",question="algorithm")
print(prompt)
print(type(prompt))
```
